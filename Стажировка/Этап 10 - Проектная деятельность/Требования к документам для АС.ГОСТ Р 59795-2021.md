### Общие положения:
- виды, комплектность документов согласовываются с заказчиком
- содержание документов определяет разработчик в зависимости от системы
- содержание документов определяют разработчики в зависимости от объема информации, необходимой и достаточной для дальнейшего использования
## Требования к содержанию документов по общесистемным решениям
### Ведомость эскизного проекта
- содержит перечень всех документов, разработанных на стадиях АС
- Ведомость заполняют по разделам — частям проекта АС
- Документ следует выполнять по ГОСТ Р 2.106.
### Пояснительные записки к эскизному, техническому проектам
- общие положения
1. Наименования АС, наименования документов
2. перечень участвующих организаций
3. цели, назначение и области использования АС
- описание процессов деятельности объекта автоматизации(состав процедур с учетом обеспечения взаимосвязи и совместимости процессов)
- основные технические решения
1. решения по: структуре АС, взаимодействию подсистем, по взаимодействию АС со смежными системами, по численности, квалификации, функциям персонала АС и тд
- мероприятия по подготовке объекта автоматизации к вводу АС в действие
1. мероприятия по обучению персонала
2. мероприятия по приведению информации к пригодному виду для информатизации
3. мероприятия по изменению объекта автоматизации
### Схема функциональной структуры
- элементы структуры АС: функции, задачи, совокупности действий
- информационные связи между элементами и с внешней средой с кратким указанием характеристик сообщений
- схемы частей структуры
### Описание автоматизируемых функций
- исходные данные
1. перечень документов, использованных при разработке функциональной части проекта АС
- цели АС, автоматизируемые функции
1. описание автоматизируемых функций
- характеристика функциональной структуры
1. перечень подсистем АС с указанием функций, задач
2. описание процесса выполнения функций
3. пояснения к разделению автоматизируемых функций на действия
4. требования к временному регламенту, характеристикам процесса реализации
- типовые решения приводится перечень типовых решений с указанием функций, задач
