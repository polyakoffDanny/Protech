Latency (Задержка) - время, которое проходит от момента отправки команды на чтение/запись до момента начала передачи данных. Измеряется в миллисекундах (мс) или микросекундах (мкс).        
- **Физика процесса:**
- **HDD:** Задержка складывается из времени, которое нужно головке, чтобы переместиться на нужную дорожку (seek time), и времени, чтобы нужный сектор подкрутился под головку (rotational latency).
- **SSD и RAM:** Здесь нет движущихся частей, задержка определяется скоростью электрических сигналов и работой контроллера. Она на порядки ниже.
**Throughput (Пропускная способность):** - объем данных, переданный за единицу времени. Измеряется в мегабайтах в секунду (МБ/с) или гигабайтах в секунду (ГБ/со).Зависит от скорости интерфейса (SATA, PCIe), скорости вращения дисков (для HDD) и типа ячеек памяти (для SSD).

**IOPS** (количество операций ввода/вывода – от англ. Input/Output Operations Per Second) – один из ключевых параметров при измерении производительности систем хранения данных, жестких дисков (НЖМД), твердотельных диски (SSD) и сетевых хранилища данных (SAN).
По сути, _IOPS это количество блоков, которое успевает считаться или записаться на носитель._ Чем больше размер блока, тем меньше кусков, из которых состоит файл, и тем меньше будет IOPS, так как на чтение куска большего размера будет затрачиваться больше времени.  
  
_Значит, для определения IOPS надо знать скорость и размер блока при операции чтения / записи. Параметр IOPS равен скорости, деленной на размер блока при выполнении операции._

#### Характеристики производительности
Основными измеряемыми величинами являются операции линейного (последовательного) и произвольного (случайного) доступа.  
  
![image|600x360](https://habrastorage.org/r/w1560/getpro/habr/post_images/7c5/0e7/1ee/7c50e71ee508707450ab3cb1d3b64a9d.png)  
  
Под линейными операциям чтения/записи, при которых части файлов считываются последовательно, одна за другой, подразумевается передача больших файлов (более 128 К). При произвольных операциях данные читаются случайно из разных областей носителя, обычно они ассоциируются с размером блока 4 Кбайт.

Принято выделять несколько типов IOPS:
1. IOPS последовательного чтения.
2. IOPS последовательной записи.
3. IOPS произвольного чтения.
4. IOPS произвольной записи.
5. TOTAL IOPS — суммарное значение IOPS чтения и записи (отличается для последовательного и произвольного доступа).

**Взаимосвязь Latency и IOPS:**  
Существует математическая зависимость. Если известна средняя задержка выполнения одной операции, максимальные IOPS можно рассчитать приблизительно так:

В жестких дисках IOPS жестко ограничены механикой.

**RPM (Revolutions Per Minute) — Обороты шпинделя:**  
Это скорость вращения пластин. Основные стандарты:
- 5400 RPM (энергоэффективные, медленные) — ~50-80 IOPS.
- 7200 RPM (стандартные десктопные) — ~75-100 IOPS.
- 10k RPM (серверные SAS) — ~120-150 IOPS.
- 15k RPM (быстрые серверные SAS) — ~180-220 IOPS.
- **Влияние на Latency:** Чем выше RPM, тем быстрее нужный сектор оказывается под головкой, снижая задержку (rotational latency). Среднее время ожидания оборота = (60 секунд / RPM) / 2.
####  RAID Penalty
RAID используется для повышения отказоустойчивости или производительности, но у него есть цена — **RAID Penalty (Штраф RAID)**.При записи данных контроллеру часто приходится делать больше физических операций ввода-вывода, чем пришла логических запросов от системы.

| **Тип массива** | **Пенальти** | **Операции**                                                              |
| --------------- | ------------ | ------------------------------------------------------------------------- |
| RAID0           | 1            | запись данных                                                             |
| RAID1           | 2            | запись данных + запись данных                                             |
| RAID10          | 2            | запись данных + запись данных                                             |
| RAID5           | 4            | чтение данных + чтение чётности + запись данных + запись чётности         |
| RAID6           | 6            | чтение данных + чтение чётности * 2 + запись данных + запись чётности * 2 |
**RAID 5 (Striping with Parity):** Данные и контрольная сумма (четность) распределены по всем дискам.
- _Write Penalty:_ **4** (Старая математика: чтобы записать новые данные, нужно: 1) Прочитать старые данные, 2) Прочитать старую четность, 3) Записать новые данные, 4) Записать новую четность). На современных контроллерах с кэшированием это может оптимизироваться, но формула расчета остается классической.
**RAID 6 (Striping with Double Parity):** Две контрольные суммы.
- _Write Penalty:_ **6** (Аналогично RAID 5, но операций с четностью вдвое больше).

```ini
T = (I * N * W)/P + I * N * R
```

Где T — вычисляемое значение IOPS массива, I — IOPS диска, N — количество дисков, P — пенальти, W — процент записи, R — процент чтения.

Пример 1. RAID5 массив из 10 дисков. IOPS одного диска — 200. Посчитаем IOPS массива при 20% операций чтения и 80% операций записи.

```ini
T = (200 * 10 * 0.8)/4 + 200 * 10 * 0.2
T = 800 IOPS
```

### Вычисление требуемого количества дисков для достижения заданного IOPS

```ini
N = T / ( I * (W/P + R))
```

Где N — вычисляемое количество дисков,  T —  IOPS массива, I — IOPS диска, P — пенальти, W — процент записи, R — процент чтения.

Пример. Сколько нужно дисков, чтобы получить 1700 IOPS при использовании RAID5 массива (80% операций чтения и 20% операций записи, IOPS одного диска — 200)? 

```ini
N = 1700 / ( 200 * (0.2/4 + 0.8))
N = 10 дисков
```


### Выносливость накопителей: TBW и DWPD

Эти метрики важны для SSD, так как ячейки памяти имеют ограниченный ресурс перезаписи.

- **TBW (Total Bytes Written):** Общий объём данных, который гарантированно можно записать на накопитель за весь срок службы. Например, 300 TBW означает, что диск «умрёт» не раньше, чем на него запишут 300 терабайт.
- **DWPD (Drive Writes Per Day):** Сколько раз можно полностью перезаписать весь объём диска каждый день в течение гарантийного срока (обычно 3-5 лет).
- _Формула:_ DWPD = (TBW) / (ёмкость в ТБ) / (365 × срок службы в годах).
- _Пример:_ Диск на 1 ТБ с DWPD = 1 означает, что каждый день в течение 5 лет на него можно записывать по 1 ТБ данных.
